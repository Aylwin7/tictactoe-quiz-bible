# TicTacToe Quiz Bible

This app is designed as an ice breaker for a connect group. It combines a fun tic-tac-toe game with quiz-style Bible questions to help group members engage and connect.

## Purpose

- Provide a light, interactive activity for connect group gatherings
- Encourage conversation through a mix of game play and Bible-themed quiz questions
- Offer a simple way for group members to participate and learn together

## Tech stack

- React
- Vite
- Tailwind CSS v4

## How to run

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the dev server:
   ```bash
   npm run dev
   ```
3. Open the app in your browser and use it during your connect group session.

## Notes

- The app uses `@tailwindcss/vite` and `tailwindcss` for styling
- `react-confetti` is included for celebration effects when a round is won
